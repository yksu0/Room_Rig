The loop

Hub → Room → Scan → Benchmark. Set up a room, drag furniture, run coarse sims, then Apply improvements back into the live layout.

  • Hub — rooms, score rings, history
  • Room — 2D / 3D layout editor + Auto-Rig
  • Scan — approximate seed when the camera cooperates
  • Benchmark — airflow, lighting, ergonomics, spatial, Community

Honesty limits

Benchmark scores are layout estimates — not CFD, radiosity, or survey-grade scan. Prices are mid-market PH estimates with a published basis.
